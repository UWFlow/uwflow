@README.md

This is one Git repository. The frontend is in `frontend/`; backend services,
Hasura, Nginx, and deployment tooling remain at the root.

Read `frontend/AGENTS.md` before frontend work. Run frontend commands from that
directory or use the root `make frontend-*` targets. Local frontend skills live
under `frontend/.agents/skills/`.

Do not use Computer Use or browser UI automation unless explicitly requested.
Use terminal checks for frontend validation and ask the user to make visual
decisions or provide screenshots. Create pull requests as drafts.
